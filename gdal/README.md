# GDAL
This script fetches GeoTIFF files from different repositories,
stitches each one into a single `vrt` and builds layered `TIFF` files with different `vrt` combinations
representing different measurements, e.g., a two layer TIFF containing Solar Radiation and Temperature average data.

## Running
`./gdal.sh fetch` fetches the data.
`./gdal.sh` builds the TIFF files.
`./gdal.sh clean` removes everything generated by the script.
