# STAR - GATK Workflow
STAR sorts FASTQ files into spatially coordinated BAM files,
afterwards, GATK is used to identify genetic variations in each sample.

## Running
`./star_gatk.sh fetch` to obtain the required FAST and FASTA files.
`./star_gatk.sh` to run the script and produce genetic variations in each sample.
`./star_gatk.sh clean` to delete all the files files generated by STAR and GATK.
